# 🚀 Portfólio Yan Menephyl 2.0 - Escopo & Stack

Este documento detalha a arquitetura técnica, as tecnologias envolvidas e o escopo de funcionalidades implementadas neste ecossistema de portfólio de alta performance e conversão.

## 🛠️ Stack Tecnológica (The "Best-in-Class" Stack)

### **Front-End (Interface UI/UX)**
- **React 19 & TypeScript**: Core da aplicação, garantindo tipagem estrita e os hooks mais modernos para performance.
- **Vite**: Build tool ultrarrápida para desenvolvimento e otimização de assets.
- **TailwindCSS**: Utilitários de estilização para um design "Glassmorphism" sutil e responsividade extrema.
- **Framer Motion**: Orquestração de animações complexas, desde o *Scroll Reveal* até interações 3D de elementos.
- **Shadcn/UI & Lucide React**: Componentes de interface polidos e iconografia moderna.
- **Embla Carousel**: Sistema de carrosséis robusto com plugins de Autoplay para Cases e Depoimentos.
- **tsparticles**: Background dinâmico de rede de partículas com interatividade ao mouse.

### **Back-End (Arquitetura de Dados)**
- **Node.js & Express**: Servidor de alta escalabilidade.
- **TRPC**: Comunicação *Type-safe* entre front e back, sem necessidade de definição manual de rotas REST.
- **Drizzle ORM**: Interação com banco de dados focada em performance e segurança de tipos.
- **Zod**: Validação de esquemas de dados em tempo real.

### **Integrações & IA**
- **IA Assistant (OpenAI/Custom)**: Widget de assistência virtual com lógica de "Quick Actions" para conversão de leads.
- **React Player**: Integração de som ambiente via YouTube API (Hidden Player).

---

## 🎯 Escopo do Projeto

### **1. Experiência do Usuário (UX)**
- **Ambientação Imersiva**: Background de partículas interativo + Música ambiente controlável (Lofi/Deep Work).
- **Personalização de Marca**: Logos de "Átomos React" intercalados no fundo de seções estratégicas (About e Contact).
- **Scroll Inteligente**: Botão "Elevador" (FAB) que detecta a posição da página e alterna entre "Ir para o Fundo" e "Voltar ao Topo".

### **2. Vitrine de Conversão (Social Proof)**
- **Featured Projects**: Exibição inicial focada nos 6 melhores projetos (Brazukas, Roth, Serafim).
- **Expandable Gallery**: Menu expansível para explorar +30 projetos secundários sem poluir a visão inicial.
- **Success Cases**: Slider detalhado com métricas reais e carrossel automatizado.
- **LinkedIn UI Testimonials**: Sessão de recomendações que replica fielmente o layout profissional do LinkedIn (Dark Mode).

### **3. Ferramentas Comerciais**
- **Template Stock**: Seção de vendas de 14 templates prontos, categorizados por nicho e valor médio.
- **Smart Contact**: Acesso direto via CTA "Contrate-me", botão de WhatsApp dinâmico e download instantâneo do currículo PDF.
- **Evolução Acadêmica**: Slider de certificações ordenado por ordem numérica crescente de relevância/data.

---

> [!TIP]
> **Diferencial Competitivo:** Este projeto não é apenas uma vitrine, mas um **funil de vendas automatizado** que utiliza IA e design de alta conversão para transformar visitantes em clientes reais.
